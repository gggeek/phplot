PHPlot

What is PHPlot?

PHPlot is a graph library for dynamic scientific, business, and stock-market charts. PHPlot allows PHP developers to create pie charts, bar graphs, line graphs, point graphs, etc. from a PHP application.

Where do I start?

The PHPlot project page on GitHub is the place to go for downloads, help, and more.

What about documentation?

The PHPlot Reference Manual contains everything you need to know about PHPlot, and more. The manual is available in both HTML and PDF formats.

You can download a zip file with the HTML version of the PHPlot Reference Manual from the downloads area of the PHPlot project page.

You can read the HTML version of the manual on line here: View the PHPlot Reference Manual.

The PDF version of the manual is available here: PHPlot Reference Manual (PDF) (about 2.5 MB).

(Note: the Reference Manual might not be 100% up to date with the latest code releases.)

How much does it cost?
